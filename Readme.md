# 🔥 HeatSafe

> A real-time heat-risk and safety assistant for people exposed to high temperatures.

## 🌡️ About

HeatSafe converts real-time weather conditions into an easy-to-understand heat-risk assessment and actionable safety recommendations.

It is designed for:

- 👷 Outdoor workers
- 🎓 Students
- 🏍️ Delivery riders
- 🎪 Event organizers
- 👴 Elderly people

## 🚀 Planned Features

- 🌡️ Real-time weather data
- 🔥 Heat-risk score
- 💧 Hydration reminders
- 🧊 Work-rest recommendations
- 🚨 Extreme heat warnings
- 📊 24-hour heat forecast
- 🗺️ Heat-risk map
- 👷 Organization dashboard
